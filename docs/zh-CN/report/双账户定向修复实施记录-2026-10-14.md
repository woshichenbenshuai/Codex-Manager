### 3. 原生 Responses 与 Chat 转换的流式异常通知

适配当前同步架构，而非复制上游异步实现：

- ChatCompletionsFromResponsesSseReader 在上游响应失败、无终态 EOF、读失败、断连或空闲超时时返回 SSE 错误对象，不合成成功 finish_reason/[DONE]。共享 pump 交出的未结束 EOF 尾帧在解析 JSON 前即被拒绝，不从其中提取正文、工具、用量或终态。
- OpenAIResponsesPassthroughSseReader 保留原生终态之前及终态所在 chunk 的字节和已有上游错误事件；第一条完整派发且对应字节已转发的响应级终态生效后结束读取，忽略后续事件，不等待网络 EOF。缺少这样的终态且处于完整帧边界时追加独立 `event: error`；若仍在未结束帧中，返回 `UnexpectedEof` 并中止交付，不补换行、不派发残缺 JSON 或未结束的成功事件。终态之后的多余数据不保证继续透传。
- 原生心跳只在完整帧之间发送。通过固定大小的状态跟踪 LF、CRLF 和裸 CR 换行（包含跨网络分片的 CRLF），不把网络 chunk 当作 SSE 帧、不缓存整帧或整段回答，也不改写上游载荷。
- 原生旁路观察器通过字节位置和有序解析进度判断终态是否对应已转发数据；流结束时等待旁路结束，不再以固定 50ms 猜测解析完成。空闲超时时只追平已转发字节，避免慢解析误报成功流失败。
- 共用 SSE 终态判定只认可响应级生命周期；MCP/工具子事件中的局部 error/completed 不终止整段响应。失败状态或响应级错误不能被 completed 标题覆盖，空/无效成功载荷不算成功终态。
- 传输错误不给客户端原样拼接内部诊断或 URL；Chat 上游错误只映射标量字段，不把任意嵌套错误对象或完整响应输出序列化到错误消息。
- 空缓冲区 Read 返回 0，不消耗事件。成功终态不等于客户端已确认收到：HTTP 写入失败仍由现有 delivery_error 路径记录，本次未引入端到端送达确认协议。

范围明确：新错误通知覆盖官方 GPT 使用的原生 Responses 和 Responses→Chat 转换路径；未宣称重写所有 Anthropic/Gemini/聚合透传适配器的错误交付。共用终态分类被调用的其他路径需要全工作区回归。

## 自查后的边界修正

自查先确认原“补空行后追加错误”会意外派发未结束的成功帧，原生心跳也可能插入半截 JSON；再次审查确认不能以最后一帧是否结束推翻已经派发的终态，并发现 Chat 转换仍接受共享 pump 的 EOF 残余帧。本次闭环调整两个 reader、测试、共享 pump 的契约注释和本记录，其他未提交修复保留；鉴权、界面、端口和选路逻辑未改。

取舍明确：尚无完整终态时，完整帧间仍能发送结构化错误；半截帧无法安全地补发另一个 SSE 事件，因此保持已转发字节不变，通过读取错误中止原生 HTTP 交付，并记录终态错误和 delivery_error。完整终态已转发时，不因随后残缺的心跳注释或网络 EOF/读错改判失败。没有引入整帧缓冲、额外配置或客户端协议。已转发原始数据本身若是非法 JSON，本修正不承诺替上游修复该载荷。

| 上游情况 | 原生 Responses | Responses → Chat |
| --- | --- | --- |
| 完整成功终态后 EOF、残缺注释或读错 | 正常结束，不追加错误 | 成功 finish_reason + 一次 [DONE] |
| 完整失败终态后残缺注释 | 保留失败终态，不再追加传输错误 | 失败对象，不生成 [DONE] |
| 无终态但位于完整帧边界，随后 EOF | 结构化 SSE 错误 | 结构化 SSE 错误 |
| 终态 JSON 可解析但缺少结束空行，随后 EOF | 交付读取失败，不补分隔 | 丢弃残余帧，输出结构化错误 |
| 未成功终结前读错/空闲超时 | 根据帧边界补错或中断交付 | 输出结构化错误 |

读取/交付链已核对共享 pump → 两个 reader → manual_chunked → collector/delivery_error → response_finalize。没有修改选路或冷却策略本身，修正的是交给它们的终态结果。共享 pump 保留旧的 EOF 尾帧行为，Chat 明确校验结束空行，避免改变其他适配器；原有非流式 SSE 重建/回退也保持不变，已有文本/工具/用量重建测试保留。该表仅描述本次两个流式入口，不宣称已重写所有协议适配器或非流式回退规则。

另用现有 Node `eventsource-parser` 执行了 314 个分片/换行场景检查，覆盖 UTF-8 文本、完整边界补错、半截帧不补分隔以及跨分片心跳。执行对象是独立的边界逻辑模型与客户端解析器，不是 Rust 源码，不能替代服务编译或运行测试。

本次闭环另执行 4,246 个独立报文/终态模型检查，覆盖 LF/CRLF、各分片位置、完整终态后残余注释及未结束终态；模型能复现修正前两类误判。该数字不是 Rust 测试通过数量，不验证线程调度、类型检查或实际 HTTP 服务运行。
